# sofascore_season_collector.py

## Tipo

Collector

## Importância

CRÍTICA

## Objetivo

Descobrir todas as partidas de uma temporada e gerar o inventário mestre.

## Entrada

- unique_tournament_id
- season_id

## Saídas

- rounds.json
- round_XX_events.json
- inventory.json

## Função Estratégica

Temporada
→ Rodadas
→ Partidas
→ inventory.json

Sem este script não existe coleta massiva.
