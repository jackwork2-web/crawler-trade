# DATA MODEL

## matches
Partidas importadas do Understat.

## team_match_stats
Estatísticas por equipe e partida.

Campos principais:
- xG
- xGA
- npxG
- npxGA
- PPDA
- Deep
- xPts

## events
Eventos da partida.

Origem:
FotMob

## snapshots
Snapshots minuto a minuto.

Campos planejados:
- minute
- home_goals
- away_goals
- home_shots
- away_shots
- home_sot
- away_sot
- home_xg
- away_xg
- momentum
