# LATE GOAL DEFINITION

## Objetivo

Definir formalmente o evento que o projeto tentará prever.

## Estratégia Atual

O projeto não trabalha mais com apenas uma definição de Late Goal.

Múltiplos alvos estão sendo armazenados e avaliados:

- goals_after_60
- goals_after_65
- goals_after_70
- goals_after_75
- goals_after_80
- goals_after_85
- goals_after_90

## Critérios de Avaliação

- Frequência do evento
- Qualidade estatística
- Capacidade preditiva
- Aplicação prática
- Valor operacional para trading esportivo

## Objetivo da Pesquisa

Determinar qual janela temporal apresenta melhor equilíbrio entre:

- frequência
- previsibilidade
- rentabilidade potencial

## Status

Em validação quantitativa através dos dados históricos armazenados na tabela results.
