# PROJECT VISION

## Missão

Identificar padrões quantitativos associados a gols tardios no futebol utilizando múltiplas fontes de dados.

## Objetivos

- Construir dataset proprietário.
- Descobrir variáveis preditivas.
- Desenvolver modelos quantitativos.
- Reduzir dependência de uma única fonte.

## Fontes Estratégicas

- Understat
- SofaScore
- FotMob
- OddsPortal

## Resultado Esperado

Sistema capaz de estimar a probabilidade de ocorrência de gols tardios.
